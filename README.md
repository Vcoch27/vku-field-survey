# VKU Field Survey

Minimal React, TypeScript, and Vite scaffold for the VKU Field Survey project.
Product features are intentionally deferred beyond milestone M1.

## Prerequisites

- Node.js 22.13 or newer (Node.js 24 LTS recommended)
- npm 10 or newer

## Setup

```powershell
npm install
```

## Commands

```powershell
npm run dev
npm run typecheck
npm run lint
npm run test -- --run
npm run build
```
