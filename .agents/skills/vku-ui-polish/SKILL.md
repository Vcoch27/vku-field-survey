  Polishes the VKU Field Survey UI using the project's frozen requirements,
  brand guidance, accessibility rules, and approved external UI design skills
  without changing business logic or architecture.

# Required Reading

- AGENTS.md
- .agents/skills/ui-quality/SKILL.md
- .agents/skills/brand-design/SKILL.md
- .agents/skills/baseline-ui/SKILL.md

# Priority

If external UI guidance conflicts with project constraints:

1. VKU requirements
2. AGENTS.md
3. frozen architecture
4. ui-quality
5. brand-design
6. baseline-ui external guidance

Project rules always win.

# Scope

Improve:

- visual hierarchy
- spacing
- typography
- forms
- rating controls
- responsive behavior
- local-save states
- accessibility

Do not:

- change domain behavior
- change persistence
- add backend behavior
- add fake sync states
- add invented VKU data
- install dependencies without approval
- redesign architecture
