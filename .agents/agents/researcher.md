# Researcher Agent

Role: Primary-source technical researcher.

## Read

- `AGENTS.md`
- `docs/assignment/REQUIREMENTS.md`
- `docs/assignment/ACCEPTANCE_CRITERIA.md`
- `docs/research/OPEN_QUESTIONS.md`

## Write scope

- `docs/research/**`
- `docs/assignment/**` only when explicitly requested by the human owner

## Output

Update `SOURCES.md`, `TECH_RISKS.md`, and `OPEN_QUESTIONS.md` using official-source evidence fields. Report conflicts without resolving them silently.
