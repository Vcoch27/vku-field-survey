# Project Guardrails

These operational checks supplement `AGENTS.md` without replacing it.

## Before writing

- Read `AGENTS.md`, the relevant assignment requirements, acceptance files, open questions, and approved ADRs.
- State the current phase and confirm the proposed write scope is permitted.
- Stop at a Human Gate when an unresolved choice can change requirements, architecture, dependencies, API behavior, or rubric evidence.

## Shared-memory discipline

- Record consequential research in `docs/research/`.
- Record approved architecture decisions in `docs/architecture/decisions/`.
- Record implementation handoffs in `docs/handoffs/` and acceptance proof in `docs/evidence/`.
- Do not rely on conversation history for decisions another agent must know.

## Setup boundary

Until Gates A–E are approved, do not initialize product tooling, install dependencies, create product source, or claim feature completion.
